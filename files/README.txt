Apni saari PDF aur HTML files isi folder (files/) mein daalo.
Delete mat karna is README ko, bas baaki files iske saath rakh do.

Naam ke rules (build script khud pehchanti hai):
- .html file            -> Mock Test
- .pdf jisme "key" ya "ans" likha ho -> Answer Key
- baaki .pdf            -> Question Paper
- Set number: file ke naam mein pehla 1-2 digit ka number (jaise "VP AIR 4 paper.pdf", "Test 07 key.pdf")

Ek set ke liye teen alag-alag files honi chahiye (paper, key, mock).
